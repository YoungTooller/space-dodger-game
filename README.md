# Space Dodger

Бесконечная 2D-аркада на **Phaser 3**: космический корабль уклоняется от летящих
навстречу астероидов и дронов, собирает бонус «Щит» и бьётся за рекорд,
который сохраняется в `localStorage`.

## Структура проекта

```
space-dodger/
├── index.html               # ЛЕНДИНГ: описание игры, кнопка «Играть»
├── .gitignore
├── package.json              # опциональный npm-скрипт для live-server
├── css/
│   └── landing.css           # стили лендинга
├── game/                      # САМА ИГРА (Phaser 3)
│   ├── index.html             # точка входа игры, подключает Phaser (CDN) и скрипты
│   ├── css/
│   │   └── style.css          # полноэкранный адаптивный холст
│   └── js/
│       ├── main.js             # конфигурация Phaser.Game, точка запуска
│       └── scenes/
│           ├── PlayScene.js     # игровая логика: движение, спавн, столкновения, сложность
│           └── GameOverScene.js # экран Game Over: очки, рекорд, рестарт
└── README.md
```

Лендинг (`index.html` в корне) — это страница, с которой обычно и «запускают»
игру: короткое описание механик, блок про управление и кнопка «Играть»,
ведущая на `game/index.html`. Сама игра при этом полностью самодостаточна и
может открываться напрямую по прямой ссылке на `game/index.html`, минуя
лендинг.

Скрипты игры подключены как обычные `<script>`-теги (без сборщика), поэтому
классы `PlayScene` и `GameOverScene` должны идти в `game/index.html` **до**
`main.js`.

## Механики

- **Управление**: `←`/`→` или `A`/`D` на ПК; тап/удержание по левой или правой
  половине экрана на мобильных.
- **Бесконечный режим**: скорость всех препятствий растёт каждые 15 секунд
  (множитель ×1.12, до потолка ×3.2), интервал спавна сокращается.
- **Счёт**: +1 очко за каждое препятствие, которое ушло за нижнюю границу
  экрана без столкновения.
- **3 типа препятствий**:
  - маленький быстрый астероид;
  - крупный медленный астероид;
  - дрон, летящий по синусоиде (зигзаг) со средней скоростью.
- **Бонус «Щит»**: появляется случайно (раз в 9–13 секунд), даёт 3 секунды
  неуязвимости — столкновение с препятствием в этот момент лишь уничтожает
  препятствие.
- **Game Over**: показывает набранные очки и рекорд (или пометку «Новый
  рекорд!»), рекорд хранится в `localStorage` под ключом `spaceDodgerBest`.
- **Адаптивный холст**: режим `Phaser.Scale.RESIZE` — игра подстраивается под
  размер окна/экрана и пересчитывает границы мира при ресайзе.
- **Отрисовка без внешних картинок**: все спрайты (корабль, астероиды, дрон,
  щит, звёздное небо) генерируются на старте через `Phaser.GameObjects.Graphics
  → generateTexture`, поэтому никаких файлов изображений не требуется.

## Как запустить локально

Игре не нужна сборка — достаточно любого локального веб-сервера
(открытие файла `index.html` напрямую через `file://` может блокировать
некоторые браузерные API, поэтому лучше поднять простой сервер). Сервер нужно
запускать из корня проекта (`space-dodger/`), чтобы одновременно работали и
лендинг, и сама игра в `game/`.

### Вариант 1 — через npm и live-server (рекомендуется)

```bash
cd space-dodger
npm start
```

Это выполнит `npx live-server . --port=8080` и откроет лендинг
`http://127.0.0.1:8080` в браузере с автоперезагрузкой при изменении файлов.
С лендинга кнопка «Играть» ведёт на `http://127.0.0.1:8080/game/`. Если
`live-server` не установлен глобально, `npx` скачает его временно — интернет
нужен один раз.

### Вариант 2 — глобальная установка live-server

```bash
npm install -g live-server
cd space-dodger
live-server .
```

### Вариант 3 — встроенный сервер Python (без npm)

```bash
cd space-dodger
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере.

### Вариант 4 — расширение VS Code

Установите расширение **Live Server** в VS Code, откройте папку
`space-dodger` и нажмите «Go Live» в статус-баре.

## Полностью офлайн-запуск (без CDN)

По умолчанию `game/index.html` подключает Phaser с CDN
(`cdnjs.cloudflare.com/.../phaser.min.js`), а лендинг `index.html` в корне —
шрифты с Google Fonts. Чтобы играть полностью без интернета:

1. Скачайте `phaser.min.js` (версия 3.70.0) с
   <https://github.com/phaserjs/phaser/releases>.
2. Положите файл в `space-dodger/game/libs/phaser.min.js`.
3. В `game/index.html` замените строку с CDN на:
   ```html
   <script src="libs/phaser.min.js"></script>
   ```
4. При желании уберите блок `<link>` с Google Fonts из корневого
   `index.html` — лендинг корректно откатится на системные шрифты.
